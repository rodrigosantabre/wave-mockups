🔗 Flujo del formulario

Contact Us → Enviar → Thank You Form

El plugin redirige aquí al enviar. Esta URL también sirve para medir conversiones en GA4 (página de "gracias" = evento de lead).

😌 Tranquilizar + retener

El usuario que envía un form entra en incertidumbre ("¿llegó? ¿cuándo responden?"). Esta página lo resuelve: confirma, da tiempo estimado, ofrece WhatsApp para los impacientes, y — clave — lo mantiene en el sitio explorando tours en vez de irse.

Página estándar de WordPress (no es de WooCommerce). Se arma con bloques de Gutenberg y el plugin de formularios solo la usa como destino de redirect.
HHeader / FooterGLOBAL

Del tema, menú v3.

1Success heroCUSTOM

Cover con check amarillo + mensaje. Si el form pasa el nombre por URL, se puede personalizar ("Thanks, Sarah"). Si no, mensaje genérico.

2What Happens NowCUSTOM

Timeline de 3 pasos. Estático. Baja la ansiedad post-envío y aclara el tiempo de respuesta.

3WhatsApp CTACUSTOM

Para quien no quiere esperar el email. Button a wa.me con mensaje pre-llenado.

4Explore toursCUSTOM

Columns con 3 tours destacados. Mantiene al usuario navegando (retención) en vez de abandonar tras enviar.

RRedirect del formPLUGIN

En WPForms / CF7 se configura "confirmation → redirect" a esta URL. También ideal para el tracking de conversión (GA4 / Meta Pixel).

🎯 Notas para el equipo

😌 Reduce ansiedad

Confirma que el mensaje llegó y da tiempo estimado de respuesta. El usuario no queda con dudas de si el form funcionó.

💬 Vía rápida

WhatsApp para los que no quieren esperar. Reduce la sensación de "envié y no pasó nada".

🔄 Retiene

En vez de un callejón sin salida, invita a explorar tours. Aprovecha el momento de interés para seguir navegando.

📊 Mide conversión

Esta URL es el "goal" en GA4: cada visita = un lead de contacto capturado. Útil para medir el rendimiento del form.
